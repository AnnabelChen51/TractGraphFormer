# TractGraphFormer

__TractGraphFormer: Anatomically Informed Hybrid Graph CNN-Transformer Network for Interpretable Sex and Age Prediction from Diffusion MRI Tractography__

To run the code, please start with the run.sh script.

This code implements a hybrid Graph CNNTransformer deep learning framework tailored for prediction tasks based on diffusion MRI tractography, as described in the following paper:

Chen, Y., Zhang, F., Wang, M., Zekelman, L.R., Cetin-Karayumak, S., Xue, T., Zhang, C., Song, Y., Rushmore, J., Makris, N. and Rathi, Y., 2025. TractGraphFormer: Anatomically informed hybrid graph CNN-transformer network for interpretable sex and age prediction from diffusion MRI tractography. Medical Image Analysis, 101, p.103476.
